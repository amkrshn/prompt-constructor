# Getting started

1. Install Node.js 20 or newer.
2. Run `npm run check` from the repository root.
3. Run `npm run build:standalone`.
4. Serve `dist/standalone` using any static HTTP server.
5. Open `index.html?mode=text`, `?mode=image`, or `?mode=presentation`.

The repository intentionally avoids external runtime dependencies in the standalone baseline.
