# Presets

Built-in style presets are neutral demonstration defaults and may be replaced or extended by the consuming product.

Palette roles are always stored as: background, primary text, accent, secondary surface. Font presets contain heading and body font names only; font files are not bundled.

Do not encode a customer's proprietary brand guide directly into the reusable repository. Product-specific brand data should live in the consuming application or in a separate private configuration package.
